# AntiGoblin 1.4.2

## Discord: голос и стримы

Пресет Discord теперь включает медиа-сети `104.29.0.0/16` и
`66.22.192.0/18` вместо списка отдельных наблюдавшихся адресов. При смене
голосового сервера или сервера трансляции новые IP внутри этих сетей больше
не требуется добавлять вручную.

Сохраняются свои домены, CIDR и дополнительные адреса из профиля. Галка
«Голос и стримы Discord» по-прежнему управляет медиа-правилами пресета;
`geosite:discord` остаётся для сайтов. Сети могут обслуживать другие приложения:
это практическое покрытие, а не эксклюзивный официальный список IP Discord.

После обновления откройте панель и нажмите **«Сохранить и применить»**, чтобы
обновить правила групп с выбранным сервисом Discord. Обычные ручные группы
не меняются автоматически: при необходимости добавьте Discord в существующую
группу через каталог. Затем переподключите голосовой канал или просмотр стрима.

Включены все изменения [1.4.1](v1.4.1.md), включая запуск обновлялки без
`nohup`. При первом переходе со старой версии, где обновление останавливается
с `nohup: not found`, установите `coreutils-nohup` и повторите обновление.

## English

The Discord preset now uses `104.29.0.0/16` and `66.22.192.0/18` instead of
individual observed media IPs. New voice and stream destinations inside those
ranges no longer need manual host rules. Custom rules are retained, and the
Discord media checkbox still controls preset-owned media routes. Shared
addresses may serve other applications; this is not an exclusive official
Discord IP allocation.

After updating, open the UI and choose **Save and apply** for catalog-managed
Discord groups, then reconnect voice or streams. Plain manual groups remain
unchanged; add Discord through the service picker if needed. All 1.4.1 fixes
are retained. Older updaters that fail with `nohup: not found` need
`coreutils-nohup` once to install this release.
