# AntiGoblin 1.4.1

Исправлен запуск штатного обновления на минимальном Entware без `nohup`.
Worker теперь игнорирует SIGHUP средствами shell и получает отдельные
stdin/stdout/stderr, поэтому продолжает работу после завершения CGI-запроса.
Короткое ожидание перед первым ответом статуса предотвращает ложное сообщение
об остановленном worker в момент его запуска.

Сохраняются все изменения [1.4.0](v1.4.0.md): NAD / BluOS, адаптивная вёрстка
и документация отдельной DNS-настройки Instagram.

Если обновление уже установленной старой версии завершается сразу с
`nohup: not found`, для одного перехода установите в Entware пакет
`coreutils-nohup` и повторите штатное обновление. Версия 1.4.1 больше не
требует этой утилиты для последующих запусков.
