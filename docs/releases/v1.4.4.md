# AntiGoblin 1.4.4

## Видимый процесс обновления

Во время обновления панель показывает текущий этап:
**подготовка → скачивание → установка → проверка**. Индикатор активности и
пояснение остаются видимыми, пока кнопки редактирования заблокированы.
Проценты не отображаются: установщик не измеряет долю выполненной работы.

При временной недоступности панели появляется статус переподключения.
Последний известный этап сохраняется, опрос продолжается. Длительное
обновление больше не останавливает проверку статуса после 15 минут.
Завершение и ошибка отображаются явно; после успеха панель перезагружается.

Новый индикатор работает в интерфейсе 1.4.4. При переходе из более старого
интерфейса до его перезагрузки может отображаться прежний экран обновления.

## Панель кнопок

Убрана прямоугольная подложка за верхними кнопками. Панель находится в потоке
страницы и не накладывается на содержимое при прокрутке. Сохранены цвета,
кнопки и масштаб существующего интерфейса. Обновлены ключи браузерного кэша.

Проверены этапы, ошибка и переподключение, сохранение блокировки редактирования,
мобильная и настольная вёрстка. Локальный патч установлен на реальном роутере
без изменения профиля и перезапуска туннелей.

Включены возможности [1.4.3](v1.4.3.md): галочка VPN-группы по умолчанию и
политика `no_vpn`. Если обновлялка старой версии останавливается с
`nohup: not found`, для первого перехода установите в Entware
`coreutils-nohup` и повторите обновление.

## English

Updates now show their actual stage: **preparing → downloading → installing
→ verifying**, with an activity indicator and persistent explanatory text.
No estimated percentages are displayed. Temporary panel downtime shows a
reconnecting state while retaining the last known stage. Long updates continue
polling after 15 minutes; completion and errors remain visible.

The new indicator is available in the 1.4.4 interface. An upgrade started from
an older interface may keep its previous update screen until the panel reloads.

The rectangular background behind the action buttons was removed. The toolbar
stays in normal page flow, preserving the existing visual style and scale.
All 1.4.3 features are retained. Older updaters failing with `nohup: not found`
need `coreutils-nohup` once to install this release.
