# AntiGoblin 1.4.8

## Запуск Xray через init на профилях с Geo-правилами

Стандартный init Entware `S24xray` запускал Xray без пути к базам
GeoSite/GeoIP. На профиле с правилами `geosite:` или `geoip:` такой запуск
завершался ошибкой загрузки `geosite.dat`, хотя init сообщал об успехе.
Так происходило при загрузке роутера, при перемонтировании USB с Entware,
при откате неудачного обновления и при ручном `S24xray restart`. Пока Xray
не поднимал self-heal, у устройств в VPN-политике не работал TCP.

Self-heal, хук перемонтирования и скрипт развёртывания теперь добавляют в
init строку `export XRAY_LOCATION_ASSET=/opt/etc/xray/dat` перед запуском
Xray. Исправление применяется само при обновлении и при каждом полном
проходе self-heal. Init с собственным путём к конфигурации не изменяется.
Исходный init сохраняется в `S24xray.bak-antigoblin-confdir`. Перед заменой
проверяется результат, поэтому init не может стать пустым.

На стенде со стоковым init с роутера Keenetic, Xray 25.5.16 и Geo-профилем
Xray поднимался при перезапуске init, при старте как после загрузки и через
хук перемонтирования. Повторный проход self-heal init не менял.

## English

The stock Entware `S24xray` init started Xray without the GeoSite/GeoIP
asset directory. On profiles with `geosite:` or `geoip:` rules Xray exited
on a missing `geosite.dat` while the init still reported success. This
happened at boot, on Entware USB remount, on rollback of a failed update
and on a manual `S24xray restart`, leaving devices in the VPN policy
without TCP until self-heal started Xray again.

Self-heal, the remount hook and the deploy script now add
`export XRAY_LOCATION_ASSET=/opt/etc/xray/dat` to the init before it starts
Xray. The change is applied automatically on update and on every full
self-heal pass. Inits with a custom configuration path are left alone, the
original init is kept as `S24xray.bak-antigoblin-confdir`, and the rewritten
file is verified before it replaces the init. On a test bench with a stock
Keenetic init, Xray 25.5.16 and a Geo profile, Xray started through an init
restart, a boot-style start and the remount hook, and a repeated self-heal
pass left the init unchanged.
