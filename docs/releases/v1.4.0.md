# AntiGoblin 1.4.0

## NAD / BluOS

В каталоге появился сервис **NAD / BluOS**: приложение, онлайн-службы и
обновления устройств NAD/Bluesound. Он находится поиском по NAD или BluOS
в категории «Видео и музыка». Включите его в активную VPN-группу, чтобы
пользоваться этими службами с обычным fallback `direct` вместо полного VPN.
Spotify остаётся отдельным сервисом.

Пресет использует домены производителя и точный CDN прошивки, подтверждённый
диагностикой C700 V2. Общие сети AWS/CloudFront не добавляются. Подробный охват
и источники — в [каталоге сервисов](../service-catalog.md).

## Интерфейс

Исправлено перекрытие настроек профиля панелью правил: заполненные карточки
и поля больше не растягивают левую колонку за её границы. Исправление проверено
на ширинах окна 390, 1201, 1280 и 1400 px. Ссылки на изменённые стили и каталог
обновлены для сброса браузерного кэша.

## DNS и обновление

Добавлена [диагностика Instagram NXDOMAIN](../troubleshooting.md#instagram-nxdomain).
Если обычный DNS фильтруется, один VPN-маршрут не исправляет разрешение имён.
Доменный DoH настраивается отдельно на роутере; этот релиз не заменяет DNS
для всех пользователей автоматически. Уже настроенные `https-dns-proxy`
и доменные DNS-правила Keenetic сохраняются при обновлении приложения.

Профили, ключи и подписки сохраняются штатным обновлением через кнопку
«Обновить приложение». Локальные изменения файлов самого приложения
заменяются содержимым релиза; перед установкой создаётся recovery-снимок.

Скачивания при сборке USB-installer имеют ограниченные таймауты и повторы;
сама CI-сборка ограничена 15 минутами, чтобы недоступное зеркало не оставляло
релизный процесс зависшим. USB-архивы выпускаются для aarch64.
