# AntiGoblin 1.4.5

## Исправление нестабильного DNS

Исправлена ситуация, когда сайты переставали открываться, хотя устройство
оставалось в Wi-Fi и соединение с внешним IP работало. Обычные DNS-запросы
UDP/53 могли попадать в прозрачный UDP-прокси раньше перенаправления DNS
самим Keenetic. В результате sing-box занимал DNS-адрес роутера и запросы
завершались тайм-аутом.

UDP/53 теперь исключается перед TPROXY и обслуживается штатным DNS роутера.
При обновлении исключение устанавливается до перезапуска sing-box,
освобождающего уже созданный конфликтующий сокет. Self-heal проверяет
наличие исключения и восстанавливает его при пересборке правил.

Маршрутизация остального UDP, голосовых соединений, игр и QUIC сохраняется.
Локальное исправление проверено на реальном роутере: DNS и HTTPS с двух
компьютеров восстановились, пользователь подтвердил устойчивую работу
интернета. Пересборка UDP-правил также проверена.

## English

Fixed intermittent DNS failures where devices remained connected to Wi-Fi
and external IP addresses were reachable, but websites stopped opening.
UDP/53 could be intercepted by TPROXY before Keenetic's own DNS redirection,
allowing sing-box to bind the router's DNS address and stall queries.

UDP/53 now returns to Keenetic's native resolver before TPROXY. Upgrades
install this exception before restarting sing-box to release an existing
conflicting socket. Self-heal checks and restores the exception. Other UDP,
voice, gaming and QUIC routing retain their existing behavior.
