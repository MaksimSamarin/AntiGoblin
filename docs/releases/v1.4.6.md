# AntiGoblin 1.4.6

Автопереключение подписки больше не блокирует self-heal на время сетевых
проверок. Рабочий туннель проверяется раз в 15 минут. При сбое следуют ещё
две проверки с интервалом в минуту. Загрузка списка ключей подписки идёт
по своему расписанию (по умолчанию каждые 6 часов).

Запасные ключи проверяются на отдельных SOCKS-портах. За раунд выполняется
одна попытка переключить рабочий стек. При неудаче восстанавливаются
предыдущие конфиги и проверяется запуск служб. Если Xray не восстановился,
self-heal делает одну внеочередную попытку запуска с восстановленным
конфигом. Переключение и откат могут кратко прервать соединения, которые
проходят через общий Xray.

Проверены отдельные таймеры, восстановление после краткой ошибки,
три последовательных отказа, успешное переключение, откат после
неудачного запуска и конкурентное изменение профиля.
